# Manifest

| Function | Description |
|----------|-------------|
| [readManifest](read-manifest.md) | Reads a manifest JSON file from disk and validates it against
`DependencyManifestSchema`. |
| [writeManifest](write-manifest.md) | Serialises a manifest to pretty-printed JSON and writes it to disk. |
| [updateDependency](update-dependency.md) | Updates a single dependency entry in the on-disk manifest by ID. |
| [addDependency](add-dependency.md) | Appends a new dependency entry to the on-disk manifest. |
| [removeDependency](remove-dependency.md) | Removes a dependency from the on-disk manifest by ID. |
| [mergeManifests](merge-manifests.md) | Merges an `updated` manifest generated by the detector over an `existing`
one, optionally preserving manual entries and accumulated change history. |
| [createEmptyManifest](create-empty-manifest.md) | Creates a minimal, valid manifest with an empty `dependencies` array. |
| [readConfig](read-config.md) | Reads a YAML configuration file from disk, parses it, and validates it
against `DependabitConfigSchema`. |
| [parseConfig](parse-config.md) | Parses a YAML string into a validated `DependabitConfig`. |
| [stringifyConfig](stringify-config.md) | Serialises a validated `DependabitConfig` to a YAML string. |
| [getEffectiveMonitoringRules](get-effective-monitoring-rules.md) | Resolves the effective monitoring rules for a specific dependency URL by
merging global config defaults with any per-URL override defined in
`config.dependencies`. |
| [shouldIgnoreUrl](should-ignore-url.md) | Returns `true` if the given URL matches any exclusion rule defined in
`config.ignore` (exact URL list or regex pattern list). |
